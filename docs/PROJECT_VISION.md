# SpeakWise

## Vision

Build an AI-powered platform that helps students improve public speaking confidence while simultaneously expanding domain knowledge.

---

## Mission

To create an AI mentor that teaches, evaluates, and coaches students to become better communicators.

---

## Target Users

- College Students
- University Students
- Interview Candidates
- Public Speaking Enthusiasts

---

## Core Technologies

- Retrieval-Augmented Generation (RAG)
- Natural Language Processing (NLP)
- Machine Learning
- Large Language Models (LLMs)
- Speech Analytics
- Computer Vision
